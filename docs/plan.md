# plan.md — Портфолио-сайт (Alex)

Пошаговый план. Шаги размером в «день»/сессию, каждый заканчивается чем-то проверяемым. Деплой — в день 1, не в конце.

> Правило: не переходим к следующему шагу, пока тест текущего не зелёный.

**Пайплайн:** GitHub = исходник (+ туда коммитит Keystatic) → Amvera собирает статику и раздаёт прод. Зрители ходят только на Amvera (доступ из РФ без VPN). Cloudflare не используется нигде.

---

## День 0 — Подготовка (30 мин)
- Выбрать имя/домен, купить **нейтральный** домен `.com`/`.dev` у reg.ru (оплата рублями).
- Создать GitHub-репозиторий `portfolio` (он же — витрина кода в портфолио).
- Зарегистрироваться на Amvera, подтвердить телефон.
- **Тест:** репозиторий существует, домен куплен, аккаунт Amvera создан.

## День 1 — Скелет + деплой на Amvera ⚑
- `npm create astro@latest` (минимальный шаблон), добавить Tailwind, `output: 'static'`.
- Первый коммит и push в GitHub.
- Создать проект в Amvera, добавить `amvera.yml` (сборка `npm install && npm run build`, артефакт — `dist/`), привязать GitHub-репозиторий (или `git remote add amvera …` + `git push amvera master`).
- Привязать купленный домен в Amvera, прописать DNS у reg.ru (без Cloudflare).
- **Тест:** страница «Hello» открывается на своём домене по HTTPS **и грузится из российской сети без VPN**.

## День 2 — Дизайн-система и каркас
- Пастельные токены (свет/тёмная), типографика, `BaseLayout`.
- Хедер с плейсхолдерами переключателя языка и темы, футер.
- **Тест:** главная рендерится в выбранной палитре на мобиле и десктопе, на 375px ничего не вылезает.

## День 3 — i18n
- Конфиг i18n Astro (локали `en` и `ru`, обе с префиксом), словари UI, рабочий переключатель языка в шапке, маршруты `/en/` и `/ru/`.
- **Тест:** переключатель меняет язык интерфейса и URL, оба маршрута отвечают 200.

## День 4 — Модель контента и лента
- `content.config.ts`: zod-схема проектов (парные en/ru поля), данные `about`.
- Компоненты `ProjectCard` + `ProjectGrid`, блок «о себе» из данных.
- **Тест:** захардкоженный тестовый проект показывается на главной и на своей странице в обоих языках; кривой фронтматтер валит сборку (схема работает).

## День 5 — Страница проекта и медиа
- `ProjectLayout` (проблема→решение→результат), теги стека, ссылки (новая вкладка), галерея (`astro:assets`, ленивая), опциональный `VideoEmbed`.
- **Тест:** страница проекта показывает галерею + ссылку + (опц.) видео; проект без видео не показывает плеер.

## День 6 — Keystatic CMS ⚑
- Установить `@keystatic/core` + `@keystatic/astro`, описать `keystatic.config.ts` (projects + about, парные поля, поля картинок), маршрут `/keystatic`, GitHub-режим.
- Убедиться, что коммит из Keystatic в GitHub триггерит пересборку на Amvera (авто-привязка или ручной push).
- **Тест:** открываю задеплоенный `/keystatic`, создаю проект с картинкой из браузера → уходит коммит в GitHub → Amvera пересобирается → проект виден на проде.

## День 7 — Наполнение реальным контентом
- Через CMS завести 3 проекта на EN+RU: рабочие (из резюме), SessionTime, Discord bot. Заполнить «о себе», загрузить аватар и `resume.pdf`.
- **Тест:** все 3 проекта живые на обоих языках, с правильным проблема→решение→результат и скриншотами.

## День 8 — Полировка + P1
- Фильтр по категориям (BA / vibe-coded) и по тегам стека, тёмная/светлая тема, SEO/OG-метатеги + sitemap, страница 404, favicon, скачивание резюме.
- **Тест:** фильтры работают, превью при шаринге показывает OG-картинку, Lighthouse ≥ 95.

## День 9 — QA и запуск ⚑
- Проверка на браузерах/мобиле, a11y-проход (alt, контраст, клавиатура), проверка битых ссылок, вычитка контента на обоих языках.
- **Проверка доступа из двух регионов:** открыть сайт из российской сети без VPN и с зарубежного IP (через онлайн-чекер доступности) — грузится в обоих случаях.
- Анонс (LinkedIn).
- **Тест:** весь чек-лист зелёный, доступ из РФ и из-за рубежа подтверждён, ссылка опубликована.
