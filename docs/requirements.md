# requirements.md — Портфолио-сайт (Alex)

> Персональный сайт-визитка: инфо о себе + проекты (BA-работа и завайбкоженные), с двуязычием RU/EN и добавлением проектов через веб-CMS.

## Vision

Одностраничный (по сути) статический сайт-портфолио, который позиционирует Alex под пивот в AI-консалтинг / solutions engineering и одновременно сам служит демонстрацией вайб-кодинга. Каждый проект подан не списком технологий, а через связку **проблема → решение → результат** — это использует BA-бэкграунд и отличает сайт от типового dev-портфолио. Контентом управляет сам Alex из браузера, без правки кода.

---

## Функциональные требования

Приоритеты: **P0** — без этого v1 не выкатываем, **P1** — сразу после запуска, **P2** — бэклог.
Каждый критерий проверяется человеком меньше чем за минуту.

### P0 — ядро

- **FR-1. Блок «о себе» вверху.** Верхний экран: имя, хедлайн (позиционирование), аватар, соцссылки, кнопка резюме.
  *AC:* открываю `/` — всё перечисленное видно на первом экране без скролла на десктопе.

- **FR-2. Лента проектов с двумя категориями.** Проекты делятся на `BA` и `vibe-coded`, с возможностью отфильтровать/разделить.
  *AC:* на главной вижу все опубликованные проекты, сгруппированные или переключаемые по категории; переключение категории меняет набор карточек.

- **FR-3. Страница проекта.** Отдельная страница: заголовок, проблема→решение→результат, теги стека, ссылки, галерея.
  *AC:* клик по карточке открывает страницу со всеми полями; отсутствие необязательного поля не ломает страницу.

- **FR-4. Добавление/редактирование проектов через веб-CMS без кода.** Админка в браузере (Keystatic, GitHub-режим).
  *AC:* на задеплоенном `/keystatic` создаю проект, заполняю поля, загружаю картинку, жму publish → уходит коммит в GitHub, после передеплоя проект на сайте.

- **FR-5. Двуязычие RU/EN с переключателем.** Весь UI и контент на обоих языках.
  *AC:* переключатель языка меняет язык интерфейса и контента, оставаясь на той же странице; язык отражён в URL (`/` vs `/ru/`).

- **FR-6. Встраивание ссылок, картинок, скриншотов.** У проекта — внешние ссылки и галерея изображений.
  *AC:* проект показывает ≥1 внешнюю ссылку (открывается в новой вкладке) и галерею из ≥2 картинок с ленивой загрузкой.

- **FR-7. Адаптив и доступность.** Корректная вёрстка на мобиле, базовая a11y.
  *AC:* на ширине 375px ничего не вылезает за экран; у всех картинок есть alt; контраст текста ≥ WCAG AA.

- **FR-8. Деплой на свой домен, доступный обеим аудиториям.** Сайт на купленном домене по HTTPS.
  *AC:* открываю свой домен — сайт отдаётся по https без ошибок сертификата и открывается из российской сети **без VPN**.

### P1 — сразу после запуска

- **FR-9. Видео у проекта (опционально).** Встраивание YouTube/Vimeo по ссылке.
  *AC:* проект с video-ссылкой показывает работающий плеер; без ссылки — пустого плеера нет.

- **FR-10. Скачивание резюме (PDF).**
  *AC:* кнопка «Резюме/CV» отдаёт актуальный PDF.

- **FR-11. Тёмная/светлая тема (пастель в обеих).**
  *AC:* переключатель темы сохраняется между перезагрузками; обе темы проходят AA.

- **FR-12. SEO / OG-метатеги / sitemap.**
  *AC:* при шаринге ссылки проекта в превью виден заголовок, описание и OG-картинка; существует `/sitemap-index.xml`.

- **FR-13. Фильтр по тегам стека.**
  *AC:* выбор тега оставляет только проекты с этим тегом.

### P2 — бэклог

- **FR-14. Контактная форма** (через Formspree, без бэкенда). *AC:* отправка формы приводит к письму; есть антиспам.
- **FR-15. Приватная аналитика** (Plausible/Umami/Яндекс.Метрика; без Cloudflare). *AC:* просмотры считаются без cookie-баннера.
- **FR-16. Раздел заметок/блога.** *AC:* markdown-посты рендерятся на `/blog`.
- **FR-17. Лайтбокс для галереи.** *AC:* клик по картинке открывает её в оверлее.

## Модель контента (что заполняется в CMS)

**Проект** (коллекция `projects`, одна запись = оба языка):
- `title`, `summary`, `problem`, `solution`, `result` — парные поля `{ en, ru }`
- `category`: `ba` | `vibecoded`
- `role`, `period` — короткие подписи (парные)
- `tech` — список тегов (общий)
- `links` — список `{ label, url }` (repo, live, прочее)
- `cover` — обложка; `gallery` — список картинок
- `video` — url (опционально)
- `featured`, `order`, `draft` — управление показом

**О себе** (singleton `about`): имя, хедлайн (парн.), био (парн., markdown), аватар, локация, языки, соцссылки (github/linkedin/email/telegram), файл резюме, текст CTA.

## Нефункциональные требования

- **Бюджет:** CMS — $0; хостинг — недорогой рублёвый тариф Amvera (порядка сотен ₽/мес); домен `.com`/`.dev` ≈ $10–15/год (оплата рублями у российского регистратора).
- **Производительность:** Lighthouse ≥ 95 по всем категориям на странице проекта; по умолчанию ноль JS, кроме островков (переключатель языка/темы, фильтр).
- **Скорость:** первая загрузка < 1.5 c на 4G.
- **Доступность из двух регионов (критично):** сайт открывается из РФ **и** из ЕС/США без VPN. Прод размещается на российском хостинге (Amvera) — он доступен из РФ нативно и из-за рубежа тоже. Западные хостинги/CDN (Vercel, Netlify, Cloudflare) в проде не используются: из РФ они заблокированы или нестабильны.
- **A11y:** WCAG 2.1 AA.
- **Приватность:** без сторонних трекеров по умолчанию; шрифты self-hosted.
- **Поддерживаемость:** добавление проекта — только через CMS, без правки кода.
- **Безопасность:** секретов в репозитории нет; GitHub App для Keystatic ограничен одним репозиторием.

## Вне области v1 (Out of scope)

- Кастомный бэкенд и база данных
- Аутентификация пользователей (кроме CMS/GitHub)
- Самостоятельный хостинг видео
- Комментарии, мультиавторство
- Оплаты/магазин
- Любые языки, кроме RU и EN
