# arch-rules.md — Портфолио-сайт (Alex)

Архитектурные правила. Нарушать — только с записью в «Журнал решений» внизу.

## Зафиксированный стек

| Слой | Выбор | Версия |
|---|---|---|
| Runtime | Node.js LTS | 20+ |
| Пакетный менеджер | pnpm (npm тоже ок) | latest |
| Фреймворк | **Astro**, вывод `output: 'static'` (артефакт в `dist/`) | 5+ (`npm create astro@latest`) |
| Стили | **Tailwind CSS** + слой пастельных дизайн-токенов | 4+ |
| Rich-контент | **MDX** (`@astrojs/mdx`) | latest |
| Схема контента | Astro Content Collections + **zod** | встроено |
| CMS | **Keystatic** (`@keystatic/core`, `@keystatic/astro`), GitHub-режим | latest |
| i18n | встроенный i18n Astro, локали `en` + `ru`, обе с префиксом (`/en/`, `/ru/`) | встроено |
| Картинки | `astro:assets` (`<Image>`) | встроено |
| Иконки | `astro-icon` или инлайн-SVG | latest |
| Шрифты | Fontsource, self-hosted (напр. Inter + акцентный serif) | latest |
| Исходник | GitHub (репозиторий-источник, туда же коммитит Keystatic) | — |
| Хостинг прода | **Amvera** (git push / привязка GitHub, статика из `dist/`) | — |
| Домен | нейтральный TLD `.com`/`.dev`, регистратор reg.ru (рубли) | — |
| CDN | **нет** (никакого Cloudflare/иностранного CDN в проде) | — |

Версии пиним мажорами; конкретику берём из `create astro@latest` на старте и фиксируем в lock-файле.

## Деплой-пайплайн (прод)

- Исходник живёт в GitHub. Keystatic в GitHub-режиме коммитит контент туда же.
- Amvera привязан к GitHub-репозиторию (или получает `git push amvera master`) → собирает статику (`npm install && npm run build`) и раздаёт `dist/`.
- Итог: правка в CMS → коммит в GitHub → пересборка на Amvera → обновлённый сайт. Зрители всегда ходят только на Amvera (RU-доступ без VPN).

## Запрещено в v1 (с триггером пересмотра)

- **Западные хостинги и CDN в проде** (Vercel, Netlify, Cloudflare, GitHub Pages как основной прод) — из РФ заблокированы/нестабильны. Пересмотр, только если российская аудитория перестанет быть целевой.
- **Cloudflare в любом виде** (в т.ч. как DNS-прокси) — рвёт TLS-хендшейк из РФ. Не пересматриваем, пока целимся в РФ.
- **Кастомный сервер/бэкенд** — пересмотр, если контактной форме понадобится логика сложнее Formspree.
- **База данных** — пересмотр, если проектов станет > ~100 (не станет).
- **React/Vue/Svelte** — только Astro-островки. Интерактив (переключатели языка/темы, фильтр) — минимальными островками. Пересмотр, если встраивается сложное интерактивное демо.
- **Самостоятельный хостинг видео** — не пересматриваем: только YouTube/Vimeo embed.
- **Шрифты и трекеры со сторонних CDN** — пересмотр только при добавлении приватной аналитики (и то без Cloudflare).
- **Хардкод текста в компонентах** — весь UI-текст через словари i18n. Не пересматриваем.
- **Неоптимизированные картинки > 500 КБ в репозитории** — не пересматриваем.
- **Тяжёлые анимации в ущерб перфомансу** — пересмотр при смене брендинга.

## Правила безопасности

- Секреты — только в env / дашборде хостинга, никогда в репозитории.
- GitHub App для Keystatic — доступ только к этому одному репозиторию, минимум прав.
- DNS ведём у регистратора или в Amvera; проксирование через Cloudflare запрещено.
- `npm audit` / Dependabot перед деплоем.
- Все внешние ссылки — `rel="noopener noreferrer"`, `target="_blank"`.
- Сайт статический, пользовательский ввод не исполняется.

## Правила обработки ошибок

- Схема контента валидируется zod в `content.config.ts` — при кривом фронтматтере **сборка падает громко** (лучше, чем тихо сломанная страница).
- Необязательные поля защищены в шаблонах: нет видео → нет плеера, нет галереи → нет секции.
- Локализованная страница 404.
- Картинка без alt → предупреждение линтера (a11y).
- CMS: без force-push; каждое изменение = отдельный коммит (откатываемо).

## Журнал решений

- **D1. Astro, а не Next/чистый HTML.** Контентный статический сайт, ноль JS по умолчанию, лучший перф/DX под markdown-портфолио. *Альт:* Next (тяжелее), 11ty (слабее DX под i18n+CMS).
- **D2. Keystatic, а не Decap CMS.** Нативная интеграция с Astro, типизированная схема, i18n и картинки из коробки, редактирование из браузера через GitHub-режим. *Альт:* Decap (возня с git-gateway), Sveltia.
- **D3. Двуязычие через i18n Astro, обе локали с префиксом (`/en/`, `/ru/`).** Явный переключатель в шапке, симметричные URL. *Альт:* дефолт без префикса (менее очевидно для пользователя).
- **D4. Один проект = одна CMS-запись с парными en/ru полями.** Оба языка держатся вместе — сложнее забыть перевод. *Альт:* отдельная запись на локаль (рассинхрон).
- **D5. Прод на Amvera (RU-хостинг) + нейтральный домен, без Cloudflare.** Сайту нужны обе аудитории без VPN: западные хостинги/CDN (Vercel частично, Netlify полностью заблокированы, Cloudflare нестабилен) отваливаются из РФ, а RU-хостинг доступен и из РФ, и из ЕС/США. Нейтральный TLD — под международное позиционирование. *Альт:* GitHub Pages (иностранная инфра, из РФ «обычно ок», но без гарантии) — как запасной; Vercel/Netlify/Cloudflare отклонены по RU-доступу.
- **D6. GitHub — источник, Amvera — прод.** Keystatic коммитит в GitHub, Amvera собирает оттуда; CMS/GitHub касается только автор, зрители ходят на Amvera. *Альт:* хостить исходник прямо в git Amvera (теряем GitHub как витрину кода в портфолио).
- **D7. Контент в формате проблема→решение→результат.** Использует BA-бэкграунд, отличает от типового dev-портфолио.
- **D8. Стек почти за $0.** CMS и исходник бесплатны, платный только дешёвый рублёвый хостинг + домен — под личный сайт нормально.
